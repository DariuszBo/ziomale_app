# 🎯 Aplikacja klastrowania użytkowników

Projekt jest interaktywną aplikacją stworzoną w **Streamlit**, która przypisuje użytkownika do odpowiedniego klastra na podstawie odpowiedzi udzielonych w ankiecie.  

Model klastrowania został wytrenowany przy użyciu **PyCaret**, a aplikacja umożliwia wizualizację statystyk dla użytkowników o podobnych profilach.

---

## 🚀 Funkcjonalności

- 📋 Wypełnianie ankiety w aplikacji webowej
- 🧠 Automatyczne przypisanie do klastra przy użyciu wytrenowanego modelu  
- 📊 Wizualizacja statystyk dla danego klastra  
- 🔍 Analiza profilu użytkownika na tle podobnych osób  

---

## 🛠 Technologie

- Python 3.11 
- Streamlit  
- PyCaret  
- Pandas  
- plotly
